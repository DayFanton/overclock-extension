Справка по функциям

⚡ Управление скоростью:

  • Ctrl + Колесо мыши: плавное изменение скорости видео под курсором.
  • Ctrl + ЛКМ: сброс скорости на 1.0x.
  • Ctrl + Shift + цифры: прямое написание любой скорости (например, 2.5x).

⏩ Перемотка:

  • J / L: быстрая перемотка назад / вперед на заданные секунды.
  • < / > (Запятая / Точка): покадровая перемотка назад и вперед.
  • 0-9: переход к % видео (0 = 0%, 5 = 50%, 9 = 90%).

⏱ Ввод таймкода:

  • Зажмите ALT и нажмите цифру, чтобы начать ввод таймкода. Далее ALT можно отпустить.
  • Формат ввода [00:00:00]. Наберите 200 — получите 2:00 мин.
